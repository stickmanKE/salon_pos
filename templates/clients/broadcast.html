How to import into Google / iPhone / Android ▸

Google Contacts (Android / Web):
Download the .vcf → Open contacts.google.com → Click Import → Select the .vcf file.

iPhone (iOS):
AirDrop or email yourself the .vcf file → Tap it on your iPhone → Tap "Add All Contacts".

Samsung / Android:
Transfer the .vcf to your phone → Open Contacts app → Menu → Import → Select .vcf file.

WhatsApp Bulk:
Import contacts to your phone first (above), then use the WhatsApp section on this page to message each one.
